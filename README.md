# c-lock 专注时钟

一个 Windows 桌面番茄钟：悬浮球 + 毛玻璃控制面板，帮你专注当下。

## ✨ 特性

- **悬浮球**：半透明玻璃质感，实时显示剩余时间；可拖动、贴边吸附（带回弹动画）、悬停展开；右键退出
- **毛玻璃面板**：点击悬浮球弹出、居中显示，背景图片做模糊磨砂
- **自定义番茄钟**：专注 / 短休 / 长休时长、长休间隔均可配置
- **自动接续**：一段结束自动进入下一段，带 3 秒缓冲、可取消
- **任务命名**：每段专注可命名，统计按任务拆分
- **历史统计**：今日 / 本周柱状图，含总时长与按任务明细
- **系统托盘**：托盘图标显示剩余分钟，菜单可暂停 / 停止 / 退出
- **本地存储**：SQLite 记录 + JSON 配置，全部保存在本地 `data/` 目录

## 🖥️ 界面

| 元素 | 说明 |
|---|---|
| 悬浮球 | 显示 `MM:SS`；左键点击展开/收起面板；拖动贴边自动吸附；右键弹出「退出」 |
| 控制面板 | 倒计时、任务下拉、开始（大圆按钮）/ 统计 / 设置 |
| 统计窗口 | 今日 / 本周柱状图 |
| 设置对话框 | 时长、自动接续、置顶、提示音等开关 |

## 🧰 环境要求

- Windows
- Python 3.10+（本机实测 3.13.9）

## 📦 安装依赖

```bash
pip install PySide6 pystray Pillow
```

## ▶️ 运行

```bash
python main.py
```

或双击 `start.bat`（以无控制台窗口方式运行；若你的 Python 路径不同，请先修改脚本中的解释器路径）。

## 🎯 使用说明

1. 悬浮球默认出现在屏幕右侧，左键点击展开控制面板
2. 在「任务」下拉框选择或输入任务名，点「开始」进入专注
3. 一段结束自动接续下一段；过渡期点「取消自动」可中断
4. 右键悬浮球 →「退出 c-lock」结束程序
5. 托盘图标：右键菜单可显示悬浮球 / 暂停 / 停止 / 退出

## 📁 项目结构

```
c-lock/
├─ main.py              入口
├─ start.bat            无控制台启动脚本
├─ core/                计时状态机、配置（纯逻辑，不依赖 UI）
├─ storage/             SQLite 读写与统计查询
├─ ui/                  PySide6 界面（悬浮球、面板、设置、统计、托盘）
├─ assets/              图标
├─ resource/            背景图片
└─ data/                运行时生成：c-lock.db、settings.json（已 gitignore）
```

分层约束：`core/` 与 `storage/` 不依赖任何 UI 库；`ui/` 不直接写 SQL。

## ⚙️ 配置

配置保存在 `data/settings.json`，也可在「设置」中修改：

| 项 | 默认 | 说明 |
|---|---|---|
| `focus_min` | 25 | 专注时长（分钟） |
| `short_break_min` | 5 | 短休时长（分钟） |
| `long_break_min` | 15 | 长休时长（分钟） |
| `long_break_every` | 4 | 几轮专注后进入长休 |
| `auto_continue` | true | 段结束自动接续 |
| `sound_on` | true | 提示音 |
| `task_history` | 高数、写代码 | 任务历史候选 |

## 🔒 数据

所有记录（SQLite）与配置（JSON）仅保存在本地 `data/` 目录，无任何网络上传。
